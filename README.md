# iroll

`iroll` — переносимое CLI-приложение на ПК для подготовки SDK RK3032,
сборки и выкладки IGUI, iman, RetroArch и ядер libretro.
Отдельная команда подготавливает SD с одним разделом GPT/exFAT.

Программа не запускает приложения, не записывает NOR и не устанавливает
операционную систему. Игры и BIOS не входят в пакет; игровой каталог
подготавливается отдельно с [icat](https://github.com/idleboxed/icat).

## Установка

Нужны 64-разрядный Linux x86-64, Python 3.12 или новее и `uv`.
Из каталога исходников `iroll`:

```bash
uv tool install --force -e .
iroll --help
```

Запускайте установленную команду напрямую из любой рабочей директории.
Редактируемая установка требует сохранить каталог исходников на месте.
Зависимости сборки проверяет `iroll deps`; программа их не устанавливает.

## Быстрый старт

Подготовьте локальные проекты IGUI и iman в `in/components/{igui,iman}`
рабочей директории. Допустимы каталоги или ссылки на исходные проекты.
Пути по умолчанию отсчитываются от рабочей директории, не от установки iroll.

Сборка для ПК:

```bash
iroll list
iroll deps
iroll rollout --dest out
```

Для RK3032 сначала подготовьте SDK из сохранённого локального файла NOR:

```bash
iroll sdk prepare --platform rk3032 --nor /path/to/nor.bin
iroll deps --platform rk3032
iroll rollout --platform rk3032 --dest out
```

Без селекторов собирается полный комплект доступных для платформы компонентов.
Результат — `out/system/`, инструкция и каталоги сохранений;
игры и каталог игр не создаются. Данные сборки остаются в `tmp/`, отчёты — в `logs/`.
[Рабочие каталоги и частичные обновления](docs/rollout.md),
[требования к NOR и SDK](docs/sdk.md).

## SD и ограничения

**`iroll card init` уничтожает все разделы и данные выбранного носителя.**
Это отдельная явная операция, не часть сборки. Сначала проверьте план через
`--dry-run`; порядок, подтверждение и восстановление после ошибки описаны
в [руководстве по подготовке SD](docs/card.md).

`rollout --dest /path/to/card` обновляет файлы в уже доступном каталоге;
команда не монтирует карту и не проверяет, что назначение является SD.
Перед обновлением остановите приложения. Изменённые поставляемые файлы
заменяются по умолчанию; `--ask` позволяет оставить выбранные прежние файлы.
Игры, сохранения и предпочтения не заменяются. Публикация пофайловая:
ошибка или отключение питания могут оставить частичный результат.
После успешной записи SD корректно размонтируйте.

Автоматическое переключение игровой SD между RO/RW пока не реализовано.
Разрешённые записи изменённой SRAM раз в 60 секунд и при штатном выходе
**не гарантируют устойчивость к отключению питания**.
[Профили и ограничения записи](docs/emulation.md).
