# Подготовка SD

**`iroll card init` уничтожает все разделы и данные выбранного носителя,
включая игры, настройки и сохранения. Бэкап не создаётся.**
Это быстрая подготовка файловой системы, не безопасное стирание старых данных.
Команда отделена от сборки и выкладки приложений.
Аппаратную операцию согласовывайте отдельно; команду с автоматическим `sudo`
выполняет владелец в своём терминале, не агент.

## Зависимости

Нужны 64-разрядный Linux с ядром 5.8 или новее, драйверы exFAT и loop;
запись выполняется с правами суперпользователя.

| Программа | Пакет Ubuntu/Debian |
| --- | --- |
| `lsblk` | `util-linux` |
| `sfdisk` | `fdisk` |
| `mkfs.exfat` | `exfatprogs` |
| `mount`, `umount` | `mount` |

Проверка программ не требует root или доступа к карте:

```bash
iroll card deps
```

При необходимости владелец устанавливает пакеты и загружает модули:

```bash
sudo apt-get install exfatprogs fdisk util-linux mount
sudo modprobe exfat
sudo modprobe loop
```

## Проверка плана

Принимается целый съёмный диск `/dev/sdX` или SD `/dev/mmcblkN`, не раздел.
Допустимый размер — от 64 МиБ до 2 ТиБ, логический сектор — 512 байт.
Swap, активные зависимые устройства, eMMC, символические ссылки, обычные файлы
и носители только для чтения отвергаются.

Владелец определяет устройство и сначала проверяет план:

```bash
iroll card init /dev/sdX --dry-run --json
```

Замените `/dev/sdX` настоящим именем диска. Сверьте путь, размер, модель,
серийный номер и точки монтирования. `--dry-run` не размонтирует и не записывает
на карту, не повышает права; отчёт сохраняется на ПК.
Между проверкой и записью карту нельзя переподключать.

Не выбирайте «Извлечь» или «Отключить питание» в файловом менеджере:
это удаляет носитель из ридера, а не просто размонтирует файловую систему.
Отдельное предварительное размонтирование не требуется.

## Запись

После согласования операции владелец выполняет в интерактивном терминале:

```bash
iroll card init /dev/sdX --json
```

Iroll перезапускает эту же команду через `sudo`; пароль запрашивается штатно.
Каталог запуска и его файлы принадлежат исходному пользователю, не root.
Журнал `logs/card-init/<run>/journal.jsonl` должен находиться на постоянном диске
ПК вне выбранной карты, не в RAM. Другой корень задаётся через
`--logs_dir /absolute/path/on/pc`.

Команда повторно проверяет носитель, показывает план со смонтированными разделами
и требует подтверждения. Только `y` или `Y` разрешает запись; обхода подтверждения нет.
Идентичность карты фиксируется и перепроверяется автоматически внутри операции,
переносить kernel-идентификатор из dry-run в команду не нужно.

После подтверждения iroll журналирует и размонтирует только файловые системы
выбранной карты, повторно проверяет её идентичность и открывает диск на запись.
Если размонтирование не удалось, разметка не начинается; автоматического повтора нет.
Создаются один раздел GPT/exFAT с меткой `idlebox`, `INSTRUCTIONS.md` в корне
и пустые `games/states/`, `games/saves/`. Приложения, игры, BIOS и каталог игр
этой командой не устанавливаются.

## Завершение и ошибки

Успех подтверждают итог `CARD_INITIALIZED`, `safe_to_remove: true` и запись
`complete` в журнале после синхронизации и размонтирования.
Полный readback карты и аппаратная проверка загрузки этой командой не выполняются.
После успешного завершения отключите и снова подключите ридер:
перечитывание таблицы разделов ядром намеренно не запрашивается внутри операции.

Ошибка после начала записи может оставить частично подготовленную карту.
Автоматического отката и повтора нет. Сохраните журнал, определите оставшиеся
точку монтирования или loop-устройство и освободите ресурсы до извлечения карты.
Не считайте карту готовой при ошибке или отмене.

## Границы результата

Это карта данных с одним общим разделом для приложений и игр, без загрузчика
и операционной системы. Форматирование не подтверждает поддержку разметки
прошивкой и не включает RO-политику игрового runtime.
Прошивка должна запускать `system/iman/iman`; старый плоский путь `system/iman`
с новым layout несовместим. Старые диагностические комплекты BOX2 могут
требовать исходную геометрию карты.

После подготовки используйте [rollout](rollout.md) для приложений
и отдельный импорт каталога игр. Повторный `card init` для обновления не нужен.
